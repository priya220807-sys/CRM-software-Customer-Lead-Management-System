# CRM Software: Customer & Lead Management System

A college-level full-stack CRM project built with Python Flask, SQLite, HTML, CSS and JavaScript.

## Main Features
- Login and signup
- Dashboard summary
- Customer CRUD
- Lead CRUD
- Lead status filtering
- Interaction logging
- REST API endpoints
- SQLite database
- Password hashing
- Responsive interface
- Demo data loader

## Default Accounts
Admin: `admin` / `admin123`
Sales representative: `sales` / `sales123`

## How to Run
1. Install Python 3.10 or newer.
2. Open a terminal in the project folder.
3. Create a virtual environment:
   `python -m venv venv`
4. Activate it on Windows:
   `venv\Scripts\activate`
5. Install dependencies:
   `pip install -r requirements.txt`
6. Start the application:
   `python app.py`
7. Open:
   `http://127.0.0.1:5000`
8. After login, open `/seed-demo` once to load sample data.
